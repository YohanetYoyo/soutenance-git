# Code of Conduct

## Notre engagement

Nous nous engageons à maintenir un environnement respectueux, inclusif et professionnel.

## Comportement attendu
- Respect mutuel
- Communication constructive
- Tolérance zéro pour le harcèlement

## Comportement inacceptable
- Insultes
- Harcèlement
- Discrimination

## Application
Tout comportement abusif peut entraîner une exclusion du projet.
