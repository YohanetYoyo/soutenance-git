# DevTask

DevTask est une application permettant de gérer les tâches de vos projets, qu'ils soient personnels ou professionnels.

## Installation

Clonez le projet en utilisant la commande :
```bash
git clone
```
puis créez une base de données sur phpMyAdmin et enfin ouvrez un navigateur web et écrivez : "localhost/[directory]"

## Fonctionnalités (certaines peuvent être encore en développement)

- Account creation
- Project creation
- Add, modify and delete tasks
- Change status of tasks
- Filtering and search bar
- Dashboard and statistics

## Contributions

Les pull requests sont acceptées. Pour des changements majeurs, ouvrez un issue d'abord pour discuter de ce que vous souhaiteriez changer.
